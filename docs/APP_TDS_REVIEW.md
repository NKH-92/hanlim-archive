# 업무 화면 UI/UX 검토와 앱인토스·TDS 원칙 적용

검토·적용일: 2026-09-27. 적용 범위: 로그인 후 업무 화면 전체(검색·문서 상세·등록/수정/개정/이동·보관 위치·폐기·엑셀 대장 동기화·기준정보·사용자/권한·감사·운영 관리·도움말·비밀번호·오류 화면). 공개 랜딩과 로그인 화면은 범위에서 제외했고 렌더링이 바뀌지 않았음을 픽셀 비교로 확인했다. 기능·라우트·폼 필드·권한·데이터 계약은 바꾸지 않았다.

## 1. 검토 범위

- [앱인토스 개발자센터](https://developers-apps-in-toss.toss.im/)의 `llms.txt`에 연결된 문서 261개 전체를 수집했다. [UI/UX 가이드](https://developers-apps-in-toss.toss.im/design/consumer-ux-guide)·디자인 도구·TDS 소개·비게임/게임 출시 체크리스트·서비스 오픈 정책은 정독했고, UI/UX 가이드의 이미지 예시(해요체·능동·긍정·경어·명사 나열·다크패턴 5·그래픽 오용)도 확인했다. 나머지 SDK·API·Unity·마케팅·수익화·운영 문서는 화면 설계와 관련된 원칙(피드백·오류 복구·내비게이션·권한 요청·문구·운영 공지·데이터 지속성)만 추렸다.
- [TDS Mobile](https://tossmini-docs.toss.im/tds-mobile/) 문서 67개(2026-09-16 수집본)에서 Typography·Colors·Button·Top·ListRow·ListHeader·TableRow·Border·TextField·Badge·Tab·Dialog·Toast·Result·ProgressStepper의 규격과 사용 규칙을 추렸다.
- 라이선스: TDS Mobile UI Kit, Toss Product Sans, 토스 아이콘·그래픽은 앱인토스 서비스 안에서만 쓸 수 있다. 이 사내 웹앱에는 **원칙만** 적용하고 컴포넌트·폰트·아이콘은 기존 CSS와 자체 SVG 마스크로 구현했다.

## 4. 적용 내역

- **범위 격리**: 세션이 있는 화면에만 `body.app-body`를 붙이고, 보정은 두 조각으로 나눴다. `appBase`는 요소 기본값 바로 뒤(기존 컴포넌트 규칙이 계속 이긴다), `app`은 업무 조각의 마지막에 둔다. 모든 선택자는 `:where(.app-body)`로 시작해 구체성을 늘리지 않으며, 이 조건은 `styleContracts.test.js`가 고정한다.
- **토큰**: 공유 `:root` 값은 그대로 두고(랜딩이 사용) `.app-body`에서 반경 16/10/8px, 글자 24/18/15/13px(모바일 22/17px)로 재정의했다. `--r-xl`, `--text-caption`, `--text-lead`, `--control-height-lg`를 추가하고 더 이상 쓰지 않는 `--hero-bg`를 제거했다.
- **셸**: 흰 사이드바(활성 = `--primary-soft`), 펼침 화살표, 이름·역할 사용자 카드, 흰 모바일 상단 바와 하단 탭(활성은 파랑 아이콘·글자), 둥근 명령 팔레트.
- **검색**: 장식 없는 제목 줄 + 52px 검색창, 조건 카드, 여유 있는 결과 표(PC)와 압축한 결과 행(모바일), 빠른 보기 패널의 위치 강조.
- **문서 상세**: 흰 제목 카드(뒤로 가기, 26px 제목, 번호·개정, 배지, 작업 버튼 줄과 분리된 폐기), 노란 위치 점이 있는 위치 카드, 흰 도면·랙 카드, 정렬된 정보 목록, 화살표 펼침 이력.
- **입력 폼**: 채움 입력, 섹션 간격, 숨긴 빈 상태 문단, 확인 체크 행, `취소 → 저장 후 다음 등록 → 등록` 순서의 떠 있는 저장 바, 오류 요약 해요체.
- **운영 관리·기준정보·사용자**: 경고색 없는 상태 요약, ListRow 도구 목록, 격자형 감사 필터, 회색 약한 버튼의 태그 행, 권한 체크 묶음, 한 줄 한 채움 버튼.
- **폐기·엑셀 동기화**: 중립 안전 안내, 지표 타일, 세그먼트형 결과 필터, 파랑 현재 단계, 검증 오류는 위에 한 줄 요약 + 아래 목록.
- **문구**: 화면 템플릿 약 270곳, 클라이언트 스크립트 90곳, 서버 오류·검증 약 360곳을 해요체로 바꿨다. 새로 DB에 저장되는 결과 문구 약 30곳(정기폐기 항목 결과, 이전 CSV 가져오기 행 오류, 엑셀 동기화 작업의 취소·중단 사유)도 바꿨다. 정기폐기 결과의 `동결`은 화면 표기 규칙대로 `대상 확정`으로 쓴다. 감사 요약은 원래 명사형 제목(`폐기 캠페인 완료` 등)이라 바꾸지 않았다.
- **바꾸지 않은 문구**: 엑셀 열 이름·셀 값과 내보내는 XLSX 안의 작성안내·입력 안내(공식 대장 파일 내용), 인쇄 문구, 오류 코드, 코드가 비교하는 문자열, 사용자 화면에 나오지 않는 개발자용 내부 오류(`TypeError` 등). 이미 저장된 과거 기록은 다시 쓰지 않는다. 감사·이력은 append-only 계약이고, 과거 기록을 표현 때문에 고치면 GMP 기록 무결성에 어긋나기 때문이다. 그래서 과거 기록은 예전 말투로, 새 기록은 해요체로 보인다.
- **기존 결함 수정**: 흐린 마스크 아이콘, 스타일 없는 지표 격자·확인 체크박스·폐기 기록 목록, 흩어진 개정 화면 제목 줄, 미리보기 열린 표의 잘리는 버튼, 한도 문구 불일치, 세트 화면의 개발자용 캡션(`sync_state=current`).

## 5. 적용하지 않은 것

- TDS 컴포넌트·Toss Product Sans·토스 아이콘과 그래픽: 앱인토스 전용 라이선스.
- 앱인토스 내비게이션 바·플로팅 탭바·토스 로그인·SDK 기능(햅틱, Safe Area API, 화면 캡처 차단, 권한 SDK): 일반 브라우저 웹앱에는 해당하지 않는다. Safe Area는 기존 `env(safe-area-inset-*)` 처리를 유지한다.
- 라이트 모드 전용·확대 제한: 이 앱은 원래 라이트 모드이며, 접근성을 위해 브라우저 확대를 막지 않는다.
- 진입 즉시 바텀시트·광고 관련 규칙: 해당 기능이 없고 현재도 준수한다.
- 웹폰트: 시스템 한글 서체를 쓰는 기존 결정을 유지했다(성능·자산 크기). 후속 검토 항목으로 남긴다.
- 정보구조·메뉴 구성·권한별 노출·검색 동작: 기능 변경 없이 표현만 바꿨다.

## 6. 검증

- `npm run verify`: 문법·타입·lint·형식·migration·route·생성 asset 일치와 전체 **613개 테스트 통과**. 문구 변경에 맞춰 테스트 기대 문구를 갱신했고, 새 조각의 `.app-body` 범위·배치 순서·토큰 블록을 검사하는 계약을 추가했다.
- 공개 랜딩(`/login`): HEAD의 CSS·JS와 새 CSS·JS로 각각 렌더링해 1440px·390px 전체 페이지를 픽셀 비교했다. **변경 픽셀 0**.
- 37개 화면 × PC 1440px·모바일 390px 전후 캡처(`outputs/app-ux-review-20260927/before`, `after`)와 레이아웃 지표:

- 상호작용: 빠른 보기 패널, 일괄 선택 바, 선택 문서 폐기 대화상자, 명령 팔레트(Ctrl+K), 모바일 더보기 드로어를 로컬 QA 서버에서 직접 열어 확인했다. 조회 전용 사용자로 검색·상세·도움말·권한 없음 화면도 확인했다.

## 8. 2차 정리(2026-09-27): 설명·중복 제거, 밀도, 일관성

1차 적용 뒤 "설명·메타 문구가 많고 공백이 크다"는 피드백으로 업무 화면 35개(조회 사용자 4개 별도)를 PC 1440px·모바일 390px로 다시 캡처하고 DOM을 측정했다. 기능·라우트·폼 필드명·권한·데이터 계약은 바꾸지 않았다.

- **깨진 배치(P0)**: 모바일에서 제목이 오른쪽으로 밀리던 정렬, 버튼 3개가 세로로 쌓여 화면 20%를 가리던 저장 바, 닫힌 드로어 그림자가 모든 모바일 화면 오른쪽에 비치던 문제, 한글 단어 중간 줄바꿈(`keep-all` 누락), 사용자 권한·역할 화면의 잘못된 메뉴 활성, 폐기 표 체크 칸 구분선 어긋남(`td`의 `display:grid`), 눌린 검색창·잘린 표 버튼을 고쳤다.
- **설명·중복(P1)**: 21개 화면의 제목 아래 설명, 로고 부제, 대분류의 구현 메모(`필요한 기능`) 상자, 문서 상세에서 6번 반복되던 위치 문장·배지·캡션, 제목 카드와 겹치는 정보 5행, 정상 상태 배지(`현재 대장 포함`, `사용 중`), 운영 관리 그룹 설명·중복 숫자·`고급` 배지, 도움말의 메뉴 복제 타일, 엑셀 동기화의 같은 규칙 4회 반복과 내부 필드 키·오류 코드, 권한 화면의 구현 설명, 역할 템플릿 key·행 버전을 뺐다. 감사 이력 조건은 한국어 선택 목록으로 바꿨다.
- **밀도(P1)**: 검색 제목·검색창 한 줄, 카드 없는 필터 한 줄, 결과 제목 옆 건수, 64px 행, 모바일 3줄 카드. 랙 격자는 칸 좌표 라벨 대신 선반 축. 빈 상태 축소, 0 지표·빈 표·빈 상태 필터 숨김, 사용자 관리는 승인된 사용자 먼저, 사이드바는 한 단계 그룹·한 줄 사용자 메뉴.

- **공개 랜딩**: main의 CSS·JS와 이 변경의 CSS·JS로 `/login`을 각각 렌더링한 PC·모바일 전체 페이지 스크린샷이 바이트 단위로 같았다.
- **확인하지 못한 것**: 실제 모바일 기기, Safari, 스크린리더. 운영 배포 전 로컬 DB 사본으로만 확인했다.
